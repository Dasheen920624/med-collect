- **契约** · `BusinessKnowledge` 负责自动和人工目标、旧数据合并、完整字典回填与实际内容比对。结构化知识按知识名称与类型匹配，人工选定目标保留业务标题。`SyncReviews` 固定选择、差异及审核人。`SyncService` 使用同一业务 ID 续办正文和附件，读取实际业务数据后才登记已写入。`CdssClient` 对新 PDF 使用稿件 ID 和内容散列作存储名，按实际附件内容核验。
- **复验方法** · 查待同步和异常使用 `GET /api/knowledge?sync=READY` 和 `sync=SYNC_FAILED`。成功写入使用 `sync=SYNCED`，相同跳过使用 `sync=SKIPPED`。历史稿和新版稿均可用 `GET /api/knowledge/{id}/sync-receipt` 实时对照。存在后续版本时，拿当前业务内容与该份获批稿比较，出现差异应查看版本记录。
