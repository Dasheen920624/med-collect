# 知识自动采集原型核查

## 0.1.5 页面与操作对照

本轮在浏览器中逐页打开内网原型的「知识自动采集」和正式工作台。上一轮检查覆盖菜单、接口和数据保存，遗漏了页面结构、按钮位置及跨页操作。下表按操作路径重新核对。

| 页面 | 0.1.4 的差距 | 0.1.5 的操作入口 |
| --- | --- | --- |
| 知识采集概览 | 指标卡与流程分开，最近执行重复显示同一个任务 | 四张流程卡显示任务、原文、未解析原文和待审核知识的实际数量。下方显示最近四个任务和三个配置入口 |
| 知识采集管理 | 网址、上传和搜索都要进入通用任务表单，列表主要显示计划启停 | 页首直接进入指定网址下载、手工上传和全网搜索。支持保存定时计划，立即执行可直接查看回执。按任务状态、方式和北京时间日期查询。上传产生关联的任务和执行记录 |
| 文献原文管理 | 学科、病种和资料类型挤在同一个下拉框，预览和下载藏在详情内 | 左侧学科病种树，右侧按资料类型、知识类别、格式、获取方式、采集日期和原文审核状态查询。列表可预览、下载、批量分类并进入解析结果 |
| 静态知识解析 | 与原文页共用同一张审核列表，生成结果数量不可见 | 独立解析列表显示解析状态、生成条数和最近生成时间。待核验原文可进入人工审核，已通过的原文可选择一个或多个业务模板，分别生成草稿。部分失败时可重试未完成的模板 |
| 知识审核管理 | 审核和同步混在一个状态列，原文与稿件要来回切换 | 按来源原文、人工审核、同步状态分别查询。可查看历史 AI 核对意见、审核人和时间。打开稿件可对照阅读、只看原文、只看知识，或切换同一来源的稿件。查重差异、人工审批和版本仍在本页办理 |
| 知识来源配置 | 使用情况要打开详情，启停要打开编辑框 | 表格列出备注、引用任务数和授权状态，可直接启停和查看操作日志 |
| 知识分类配置 | 使用平铺列表，调整顺序要输入数字 | 按学科病种、知识类别、资料类型切换目录，树和列表联动。支持同级上移下移、启停和引用资料查询。上级使用量按不同原文、不同知识去重 |
| 知识生成模板 | 初次打开为空，所有字段混在一张表 | 默认加载可用业务模板，分属性与内容目录，可展开收起、维护提取和必填规则、预览参数、导出及查阅日志 |

顶部专科与病种按原文已登记的学科分类过滤概览、任务、原文、解析及知识审核。任务按已关联的采集结果归属学科。查看尚未产出原文的任务时选择「全部专科」。分类配置、来源和模板为公共配置。原型其他知识中心模块不属于此次采集系统的八个子模块。

### 仍有差异的操作

- 单次可设置 1 至 100 条，支持原型常用的 50 条。全网搜索按候选网址去重，超过 20 条时继续读取 SearXNG 后续页，最多读取十页。上传仍为每批 20 个文件，每份 20 MB。原型还提供不限数量。
- 原文资料类型和知识类别可在入库后核对、批量分配和筛选。原型的按资料内容类型预筛、部分站点的专用栏目规则和机构账号接入，仍需分别适配来源。
- 对照阅读使用服务器上的原始 PDF 或其他文件的提取文本。可按页跳转、缩放或打开完整 PDF。页图从服务器原件按需生成，仅在请求期间使用。段落级证据定位尚未实现。
- 业务结构使用 4.23 返回的字段和字典映射。采集端维护本地生成规则。原型允许直接新增、删除和重排业务字段，这部分仍由业务系统维护。

### 正式工作台复验

2026-11-23 在 Oracle 正式工作台逐页实测八个入口，并核对概览和列表的数据。原文按 PDF 过滤后仅显示已同步的血压计研究。审核详情能对照原文与摘要，医学期刊的高血压条目来自业务分类字典。后端 11 项回归均通过。具体样本、校验值和回滚入口见交接记录。[节点 14](handoff.md#节点-14--按原型调整八个采集页面)

### 当时的执行规则与现场条件

- 0.1.3 验收时单次采集结果上限为 20，文件上限为每份 20 MB。原型展示了 50 条、自定义和不限量。栏目采集从指定页面提取站内链接。检索候选通过结果 ID 选取，采集使用搜索时记录的地址，并通过执行记录回溯原搜索。
- 全网检索使用 `MEDCOLLECT_SEARX_URL` 对应的 SearXNG JSON 接口。生产验收验证了搜索生成 20 条候选、选一条取得公开期刊全文和下载回读。Europe PMC 医学检索使用独立的 API。[验收交接](handoff.md#节点-12--searxng-部署与现网选采)
- 来源授权状态登记在采集系统。需要登录、机构代理或其他站点授权的来源，须配套可用的授权接入。原型的账号提交也依赖独立的来源授权服务。
- 知识生成模板的 4.23 字段 ID 和结构用真实业务模板。采集侧的规则在本应用保存，业务模板参数由 4.23 的维护流程生效。模型预审核结果供人工核对，正式同步以人工审核决定为准。
- 原型的按内容类型预筛和特定站点栏目规则依赖来源提供的标签或站点适配。此次验收覆盖已知文件格式、可读网页、来源记录区分及入库后的分类管理。

### 0.1.3 验收结果

- Vue 生产构建成功，6 项 Spring Boot 回归测试全部通过。覆盖多目标和单次计划、全网候选选采、分类关联、历史模板快照、人工审核门槛、PDF 原件与同步中断恢复、文件迁移和账号管理。浏览器通过管理员登录后逐个打开 8 个页面，核对 4 种计划、3 个分类目录、医学期刊模板和用户管理入口。
- 发布前的隔离容器从 PLOS ONE 直接采集公开论文 `10.1371/journal.pone.0155677`。原件 508632 字节，预览 SHA-256 与出版社样本一致。真实 `deepseek-flash` 生成摘要，4.23 返回 14 个知识类别入口及医学期刊模板。隔离稿按医学期刊 `31` › 高血压 `170103` 提交至待审，同步写入在隔离容器关闭。[论文来源](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0155677)
- 0.1.3 发布时通过容器健康检查，正式 Oracle 执行了 13 项迁移，包含 3 类分类目录。历史知识的类别、摘要、业务主键和 PDF 哈希通过回读。角色权限在隔离账号中验证。
