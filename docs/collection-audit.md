# 知识自动采集原型核查

2026-11-23 对照内网原型的「知识自动采集」八个入口。原型菜单以 `collection-redesign.js` 的 `rdMenus` 为准，并核对任务、来源、分类、模板和审核对应的交互脚本。

核查样本为当日原型首页及其 34 个相关脚本。首页 SHA-256 为 `1e45680e4726867776598a3f4a508a03ee5c63423a63f8839ab2a1909835bf4d`。表中以可执行入口、持久化结果和审核状态作为验收依据。

## 执行规则与现场条件

- 现网单次采集结果上限为 20，文件上限为每份 20 MB。原型展示了 50 条、自定义和不限量。栏目采集从指定页面提取站内链接。检索候选通过结果 ID 选取，采集使用搜索时记录的地址，并通过执行记录回溯原搜索。
- 全网检索使用 `MEDCOLLECT_SEARX_URL` 对应的 SearXNG JSON 接口。生产验收验证了搜索生成 20 条候选、选一条取得公开期刊全文和下载回读。Europe PMC 医学检索使用独立的 API。[验收交接](handoff.md#节点-12--searxng-部署与现网选采)
- 来源授权状态登记在采集系统。需要登录、机构代理或其他站点授权的来源，须配套可用的授权接入。原型的账号提交也依赖独立的来源授权服务。
- 知识生成模板的 4.23 字段 ID 和结构用真实业务模板。采集侧的规则在本应用保存，业务模板参数由 4.23 的维护流程生效。模型预审核结果供人工核对，正式同步以人工审核决定为准。
- 原型的按内容类型预筛和特定站点栏目规则依赖来源提供的标签或站点适配。此次验收覆盖已知文件格式、可读网页、来源记录区分及入库后的分类管理。

## 验收结果

- Vue 生产构建成功，6 项 Spring Boot 回归测试全部通过。覆盖多目标和单次计划、全网候选选采、分类关联、历史模板快照、人工审核门槛、PDF 原件与同步中断恢复、文件迁移和账号管理。浏览器通过管理员登录后逐个打开 8 个页面，核对 4 种计划、3 个分类目录、医学期刊模板和用户管理入口。
- 发布前的隔离容器从 PLOS ONE 直接采集公开论文 `10.1371/journal.pone.0155677`。原件 508632 字节，预览 SHA-256 与出版社样本一致。真实 `deepseek-flash` 生成摘要，4.23 返回 14 个知识类别入口及医学期刊模板。隔离稿按医学期刊 `31` › 高血压 `170103` 提交至待审，同步写入在隔离容器关闭。[论文来源](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0155677)
- 0.1.3 发布时通过容器健康检查，正式 Oracle 执行了 13 项迁移，包含 3 类分类目录。历史知识的类别、摘要、业务主键和 PDF 哈希通过回读。角色权限在隔离账号中验证。
